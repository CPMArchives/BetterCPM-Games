# Project principles

BetterCP/M Games is a curated collection, not an indiscriminate software
archive or a direct port of BSD Games. Sources of inspiration include BSD
and Unix, DEC and other minicomputers, mainframes, historical CP/M games,
traditional games, and original work.

Select games for enjoyment, variety, distinctiveness, historical interest,
hardware suitability, and worthwhile modernization. A difficult game remains
an editorial candidate even when its implementation must be scheduled later.

Choose the best historical edition, not necessarily the earliest. Distinguish
the selected game edition from the implementation used to reproduce it.
Avoid collecting near-identical variants without a clear reason.

Modernization may improve instructions, presentation, controls, difficulty
options, saving, statistics, and error handling. Preserve fundamental rules
and character; document deliberate departures. Historical defects and awkward
interfaces are not preservation requirements.

The collection should mix quick sessions, substantial strategy, computer
opponents, adventures, puzzles, action, and replayable challenges. The
provisional catalog is a discovery and editorial tool, not a promise to
implement every entry.

## ADVENT decision

Include Crowther and Woods's original 350-point Colossal Cave Adventure.
Preserve its locations, objects, puzzles, scoring, and fundamental mechanics.
Expanded 430-, 550-, and other point editions are outside this selection.
Improve the interface and save/resume where worthwhile. The edition is
approved; implementation selection and source permissions remain open.

## Development approaches

- **Adopt and polish:** modest improvements to a suitable CP/M implementation.
- **Adapt and modernize:** retain the core but substantially improve its
  interface, portability, or options.
- **Port or reimplement:** use another implementation or create one when no
  suitable CP/M starting point is available.
